# 1. Introduction and goals

## Purpose

`hola-hello-ciao` is a small web API. Functional scope is not yet defined; this chapter will be extended with the first requirements.

## Quality goals

| Priority | Goal | Meaning |
|---|---|---|
| 1 | Simplicity | Few moving parts; easy to run, understand and change |
| 2 | Maintainability | Typed, tested, documented; safe to evolve with AI assistance |
| 3 | Low operating cost | One process, one file database, no external services |

## Stakeholders

| Role | Expectation |
|---|---|
| Owner / developer | A lean codebase that is quick to extend |
| AI agents | Clear conventions and docs ([AGENTS.md](../../AGENTS.md)) |
